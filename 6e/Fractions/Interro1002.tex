 \subsection*{Exercice 1 (6 points)}
 

\begin{enumerate}
\item Écrire une fraction ayant $4$ comme dénominateur. 
\item Écrire une fraction ayant $7$ comme numérateur. 
\item Écrire une fraction égale à $5$ ayant $7$ comme dénominateur.
\item Écrire une fraction égale à $4$ ayant $12$ comme numérateur. 
\end{enumerate}
\subsection*{Exercice 2 (4 points)}
Recopier les égalités suivantes en complétant les pointillés. 
\begin{enumerate}
\item $\frac37=  \frac{\ldots}{42}$
\item $\frac1{9}= \frac{11}{\ldots}$
\item $\frac4{11}= \frac{36}{\ldots}$
\item $\frac{9}{13}= \frac{54}{\ldots}$
\end{enumerate}

\subsection*{Exercice 3 (6 points)}

Trier dans l'ordre décroissant les fractions suivantes : 
\[ \frac23 ; \frac 35 ; \frac56 ; \frac 3{10} ; \frac4{15}
